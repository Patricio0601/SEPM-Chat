# SEPM-Chat

SEPM-Chat is a Flask-based web application developed for the Software Engineering and Project Management (SEPM) mini-project at SRM University. It allows users to check procurement regulations for items using Suprimento de Fundos, integrating with procurement portals for real-time data.

## Features
- Check if items can be purchased with Suprimento de Fundos.
- Integration with procurement portals for real-time data.
- Chat history and daily reports.

## Prerequisites
- Python 3.11.9
- Dependencies listed in `requirements.txt`
